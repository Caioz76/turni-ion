          Salva e trasferisci i dati tra dispositivi
          —
          Il file scaricato si chiama turni_memoria.json e va tenuto nella stessa cartella Download insieme a questa pagina. Per usarlo su un altro iPhone o computer, copia entrambi i file e importa la memoria da qui. Per iCloud: scegli "Salva su File → iCloud Drive" quando esporti, così il file si sincronizza da solo tra i tuoi dispositivi Apple; sull'altro dispositivo usa "Importa memoria" scegliendolo da lì.

          Sincronizza con Google Drive

          Stessi turni su tutti i tuoi dispositivi
          Non collegato.
          Serve un Client ID Google (gratuito, una volta sola). Come ottenerlo →
          1. Vai su console.cloud.google.com (anche da Safari) e crea un progetto (basta un nome qualsiasi).
          2. Menu ☰ → API e servizi → Schermata consenso OAuth: tipo Esterno, compila i campi obbligatori, salva. In "Utenti di test" aggiungi la tua email Google.
          3. Menu ☰ → API e servizi → Credenziali → Crea credenziali → ID client OAuth: tipo "Applicazione web".
          4. In "Origini JavaScript autorizzate" aggiungi l'indirizzo esatto di questa pagina (es. https://tuonome.github.io), senza barra finale.
          5. Copia il "Client ID" generato e incollalo qui sopra.
